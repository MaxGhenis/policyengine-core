Disk-backed holder storage (`MemoryConfig`) now gives each disk storage a holder makes a folder no other storage uses, makes a missing folder the caller chose for it, removes the files dropped branches and clones wrote once they are garbage-collected, and reads a plain value stored over an enum back as plain, so a holder made again, or a second simulation given the same folder, no longer writes over or removes another's values, and repeated branches and derivatives no longer pile up files.
